# Проверка действующего сайта

`npm run test:core` запускает быстрые тесты корзины и смены города, параметров маршрута и серверной выдачи графиков уборки. Внешние сервисы не нужны.

`SITE_API_TEST_BASE_URL=http://localhost:8080/ npm run test:backend-contract` проверяет доступный только для чтения контракт каталога Самары и Тольятти. Если переменная не задана, этот тест пропускается.

При запущенных локальных фронте и API выполните `PLAYWRIGHT_BASE_URL=http://localhost:3001 PLAYWRIGHT_PORT=3001 npm run test:e2e:recent`. Браузерные тесты проверяют ссылки выбора города и страницу графика уборки. Используйте именно `localhost`: локальное правило сайта переводит `127.0.0.1` на HTTPS.

Тесты не отправляют заказы и СМС.
