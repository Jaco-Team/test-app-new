# Проверка адресов доставки

Исправление production-сценария выбора адреса согласовано пользователем отдельно от Storybook.

Подсказка Яндекса передаётся в `profile/check_street` с разделителем `, ` между районом и улицей. Улица имеет приоритет над населённым пунктом независимо от порядка компонентов и позиции `kind`. Выбранный город повторно не добавляется; другой населённый пункт сохраняется. Для нескольких `DISTRICT` используется последний, как в прежнем коде, чтобы не добавлять административные префиксы к кварталу.

Ошибка API показывает серверный `text`. Новый поиск очищает прежний адрес и `street_id`, завершение запроса всегда снимает загрузку.

Запуск без реальных API-запросов:

```sh
npx vitest run --config tests/address/vitest.config.mjs
```

Тесты покрывают бульвар Гая / Рябиновый бульвар, порядок компонентов, несколько районов, населённые пункты, пустые данные, ошибку API / исключение, выбор одного и нескольких адресов. Состояние store проверено для ширины 375 / 768 / 1280; отдельная визуальная проверка интерфейса этими тестами не выполняется.
